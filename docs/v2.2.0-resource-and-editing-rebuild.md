# ACE v2.2.0 — Resource and Editing Rebuild

This milestone replaces hard creative blocking and silent resource failure with a recoverable, observable production pipeline.

## Immediate rules

- Creative-quality warnings do not stop a generation by default.
- Only technical invalidity, unsafe/unlicensed media, or failed factual verification may hard-stop automatic production.
- Resource providers must report attempted queries, result counts, errors, rate limits, and download failures.
- A missing stock result triggers query relaxation and alternative visual routes rather than an unexplained fallback.
- `best` means more repair attempts and stronger judging, not stricter annoyance.

## Planned pipeline

```text
Story/content brief
→ scene and continuity planner
→ resource query ladder
→ provider search audit
→ preview-frame extraction
→ semantic and aesthetic judging
→ timeline grammar
→ audio/music/SFX direction
→ render
→ automatic repair
→ final validation
```

## Resource policy

ACE may use account-owned media, Pexels, Pixabay, Openverse, Wikimedia Commons, official-page captures, original explainers, generated concept media, and properly licensed audio sources. Every asset must retain provenance and license metadata. Sources with unclear rights remain reference-only and never enter a publishable export automatically.

## CLI direction

```bash
ace make "topic" --preset story
ace retry
ace repair
ace resources test "red umbrella hotel hallway"
ace review
ace open
```

Advanced commands remain available, but normal users should not need the old command tree.
